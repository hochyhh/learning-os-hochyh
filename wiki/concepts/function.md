# Функция

## In one sentence

Функция — конструкция, которая при одном значении аргумента всегда даёт только одно значение функции (свойство однозначности).

## Explanation

В лекции 02 функция разбиралась как базовое понятие рядом с [[formal-system]]: ключевое свойство — однозначность, одному значению аргумента соответствует ровно одно значение функции.

## Boundaries and common mistakes

- Однозначность ≠ «просто формула»: нарушается, если одному аргументу соответствуют два разных значения.
- Лекция не даёт формального определения (область/множество значений) — Source needed.
