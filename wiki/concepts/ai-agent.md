# ИИ-агент

## In one sentence

По лекции 01 курса кибернетики, ИИ-агент — это система из LLM, MCP и харнесса.

## Explanation

В лекции агент разложен на три компоненты:

- **LLM** — языковая модель (принимает решения, «думает»);
- **[[mcp]]** — «своего рода апи для ИИ», доступ модели к внешнему миру;
- **[[harness]]** — «руки ИИ», которые работают напрямую с ПК.

_Интерпретация (не из лекции, проверить): LLM отвечает за решения, MCP — за стандартизированное подключение к данным и инструментам, харнесс — за выполнение действий на машине. Source needed._

## Boundaries and common mistakes

- Лекция не проводит границу между «обычным чатом с LLM» и агентом.
- Не смешивать компоненты: это не синонимы, а разные роли в одной системе.
