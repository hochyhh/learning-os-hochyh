# Формальная система

## In one sentence

Формальная система — система, состоящая из алфавита, аксиом и множества встроенных формул; в лекции 02 математическая логика называется формальной системой.

## Explanation

По лекции, формальная система состоит из трёх частей:

- **алфавит** — из чего пишут объекты системы;
- **аксиомы** — исходные положения;
- **множество встроенных формул** — «встроенные» формулы системы (смысл в конспекте не раскрыт).

Математическая [[logic]] (в отличие от философской) подчёркивается как формальная система; её связывают с Джорджем Булем и булевой алгеброй.

_Интерпретация (не из лекции, проверить): «множество встроенных формул», вероятно, — правила построения/ вывода, по которым из аксиом получаются формулы. Source needed._

## Example

Булева алгебра как формальная система (упомянута в лекции как основание математической логики).

## Boundaries and common mistakes

- Не смешивать «формальную систему» и «логику» целиком: формальность — свойство математической логики, а не всех её видов.
- Состав «алфавит + аксиомы + формулы» передан из конспекта без определений компонентов — Source needed.
