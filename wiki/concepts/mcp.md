# MCP

## In one sentence

В лекции 01 MCP описан как «своего рода апи для ИИ» — компонент [[ai-agent]], связывающий LLM с внешним миром.

## Explanation

MCP — одна из трёх компонент ИИ-агента наряду с LLM и [[harness]]. Лекция даёт только метафору («апи для ИИ») и не раскрывает устройство протокола.

_Интерпретация (не из лекции, проверить): протокол описывает стандартный способ, которым модель подключается к инструментам и источникам данных; аббревиатура, вероятно, читается как Model Context Protocol. Source needed._
